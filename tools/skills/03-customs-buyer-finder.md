# Skill: 03-customs-buyer-finder (劳保用品海关数据提单与同行出海反查)

## 技能定位
专为广东铭顺劳保（足部防护、手部防护、身体工装、头部防护）工贸一体出海打造的海关提单反查引擎。支持「精准 HS 编码买家反查」、「国内同产业带出口商提单追踪」以及「目标国（中东/东南亚/独联体/欧美）活跃买家挖掘」，直接提取提单进口商（Consignee）、采购频次与重量货值，并深度穿透采购商联系方式，无缝合并写入 `data/leads.xlsx`。

## 核心 HS 编码与产品映射底册
- **6403.40 / 6402.91**：带保护性钢头/复合头防砸防穿刺安全鞋、绝缘工作靴
- **6116.10 / 6116.92**：丁腈/PU/乳胶浸胶劳保手套、耐磨棉纱防割作业手套
- **6211.33 / 6210.40**：特种工业防护工装、防静电阻燃工作服
- **6307.90 / 6217.10**：高可视反光安全背心（ANSI/EN ISO 20471 合规）
- **6506.10**：工业安全帽（ABS/玻璃钢高抗冲）

## 触发与分流规则
- **模式 A（HS 编码定向反查）**：输入指定品类海关代码与目标进口国（如 `--hs "6403.40" --country "Saudi Arabia"`），拉取目标国真实提单进口商。
- **模式 B（同行出海口岸追踪）**：输入国内劳保生产企业名称或产业带集聚地（如 `--supplier "广东" --keyword "safety boots"`），反查同类工厂货柜流向与采购商。
- **模式 C（广东铭顺全品类巡检反查）**：自动轮询铭顺劳保 5 大核心品类 HS 编码池，全自动拉取近期真实提单买家并完成去重入库。

## 支撑脚本与执行方式
```bash
# 模式 A：按 HS 编码反查特定国家劳保进口商（以沙特安全鞋为例）
python tools/customs_leads_extractor.py --mode hs --hs "6403.40" --country "Saudi Arabia"

# 模式 B：追踪广东产业带同类劳保手套出口提单
python tools/customs_leads_extractor.py --mode supplier --supplier "Guangdong" --hs "6116.10"

# 模式 C：铭顺全产品线海关潜客一键轮询提取
python tools/customs_leads_extractor.py --mode auto
